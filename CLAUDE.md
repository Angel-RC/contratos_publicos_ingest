# Reglas de programacion.

Este proyecto esta diseñando en python. Usa uv para gestionar los paquetes e instalaciones.

Emplea paquetes en lugar de hacer logica custom. Usa pydantic para contratos de datos, hydra core para ficheros de configuración, dlt para ingestas de datos. tenacity para la gestion de errores y reintentos.

Intenta simplificar el código lo máximo posible.
